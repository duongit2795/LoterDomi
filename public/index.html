Nguồn API theo game

vnlotteryplan.com: bấm Nhập game từ vnlotteryplan để thêm toàn bộ game (Siêu Tốc, M.Bắc, M.Nam, M.Trung...), bot tự lấy kết quả, kỳ sắp tới và dàn kế hoạch.
API tuỳ chỉnh: endpoint JSON bất kỳ, đường dẫn trường dạng data.list[0].issue, URL có thể chứa {ts}. Bấm Thử gọi API để xem JSON thô và giá trị trích xuất.
